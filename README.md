# Obs.ProcessMuterByChannel

Плагин для **OBS Studio**, который автоматически заглушает звук указанного процесса на ПК, когда в выбранном аудиоканале OBS появляется звук выше, чем указано в настройках (по умолчанию -60 dB).

> Пример: вы говорите в микрофон → в аудиоканале OBS появляется сигнал → плагин мгновенно приглушает звук игры/браузера/плеера, чтобы не было наложения и эха.

## ✨ Возможности

- 🎚️ **Привязка аудиоканала OBS к процессу Windows** — в настройках указывается название аудиоканала и имя процесса.
- 🔇 **Автоматическое приглушение** — как только в выбранном канале OBS появляется звук, плагин глушит аудиосессию указанного процесса на ПК.
- 🔊 **Автоматическое возвращение звука** — когда звук в канале пропадает, громкость процесса восстанавливается.
- ⚙️ **Настройка через интерфейс OBS** — не нужно редактировать конфиги вручную.
- 🪶 **Лёгкий и не требует внешних зависимостей** — работает через Windows Core Audio API.

## 🎯 Зачем это нужно

Классический сценарий

| Ситуация | Что делает плагин |
|---|---|
| Вы говорите в микрофон | Звук игры/музыки/браузера приглушается |
| Вы замолчали | Звук процесса возвращается к прежней громкости |
| В канале тишина | Процесс звучит как обычно |

Это удобно для стримов, записи видео, голосового чата и любых сценариев, где нежелательно, чтобы системный звук перебивал ваш голос.

## ⚙️ Как это работает

1. Плагин подписывается на события аудиоканала OBS с заданным именем.
2. Отслеживается уровень сигнала (наличие/отсутствие звука) в этом канале.
3. При появлении звука плагин находит аудиосессию процесса с указанным именем в Windows Volume Mixer.
4. Через Windows Core Audio API сессия переводится в режим mute.
5. Когда звук в канале пропадает — mute снимается.

> Работает на уровне **аудиосессий Windows**, поэтому процессу не требуется никаких дополнительных прав или модификаций.

## 📦 Установка

1. Скачайте последний релиз со страницы [Releases](../../releases).
2. Распакуйте архив.
3. Скопируйте папку плагина в директорию плагинов OBS:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\OBS Studio\obs-plugins\64bit
   ```

4. Перезапустите OBS Studio.

> После запуска плагин появится в меню **Сервис → Process Muter By Channel**.

---

## 🎛️ Настройка

1. Откройте OBS Studio.
2. Перейдите в меню **Сервис → Process Muter By Channel**.
3. Заполните поля:

   | Поле | Описание | Пример |
   |---|---|---|
   | **Process Name (without .exe)** | Имя `.exe` процесса, звук которого нужно глушить   | `chrome` |
   | **Monitored Audio Source** | Имя аудиоисточника в микшере OBS, за которым нужно следить | `Микрофон` |
   | **Threshold Lever** | Выше этого уровня звука начинать глушить звук процесса | `-60` dB |
   | **Fade Duration** | Время затухания\появления звука, чтобы звук не появлялся резко | `chrome.exe` |

4. Нажмите **Save**.

Готово! Теперь при появлении звука в указанном канале звук выбранного процесса будет автоматически приглушаться.

> 💡 **Подсказка:** имя процесса можно посмотреть в Диспетчере задач → вкладка «Подробности», либо в микшере громкости Windows (ПКМ по значку звука → Открыть микшер громкости).

## 🔨 Сборка из исходников

### Предварительные требования

- [.NET SDK](https://dotnet.microsoft.com/download) (версия из `SmoothMuterPlugin.csproj`)
- Visual Studio 2022 *(опционально)* или любая IDE с поддержкой C#
- Git

### Шаги

```bash
# 1. Клонируем репозиторий
git clone https://github.com/VallFreya/Obs.ProcessMuterByChannel.git
cd Obs.ProcessMuterByChannel

# 2. Собираем в Release
dotnet publish -c Release -r win-x64

# 3. Готовые файлы появятся в:
#    bin\Release\net10.0-windows\win-x64\publish
```

Скопируйте собранный плагин в папку плагинов OBS (см. раздел [Установка](#-установка)) и перезапустите OBS.

## 🗂️ Структура проекта

| Файл / папка | Назначение |
|---|---|
| `Plugin.cs` | Точка входа плагина: регистрация в OBS, колбэки загрузки/выгрузки |
| `ObsApi.cs` | Обёртка над OBS API (P/Invoke) |
| `AudioMutesManager.cs` | Менеджер приглушения: хранит состояние и управляет mute-сессиями |
| `ProcessAudioControl.cs` | Работа с аудиосессией конкретного процесса через Core Audio API |
| `Properties/` | Ресурсы и метаданные проекта |
| `exports.def` | Экспортируемые функции, которые загружает OBS |
| `SmoothMuterPlugin.csproj` | Файл проекта C# |
