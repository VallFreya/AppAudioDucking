# Автоприглушение приложений для OBS Studio

*(App Audio Ducking, репозиторий `Obs.ProcessMuterByChannel`)*

Плагин для **OBS Studio**, который автоматически приглушает звук выбранных приложений на ПК или других звуковых источников OBS, когда в отслеживаемом звуковом источнике OBS (например, в микрофоне) появляется звук громче заданного порога (по умолчанию -60 dB). Когда звук пропадает, громкость плавно возвращается.

> Пример: вы говорите в микрофон → в источнике OBS появляется сигнал → плагин плавно приглушает игру, браузер или плеер, а также, например, музыкальный источник в самом OBS, чтобы звук не перебивал голос.

## ✨ Возможности

- 🎚️ **Любое количество фильтров** — каждый фильтр связывает отслеживаемый звуковой источник OBS с целью и имеет собственные порог и время затухания.
- 🏷️ **Свои названия фильтров** — название задаётся прямо в карточке фильтра, по умолчанию «Фильтр 1», «Фильтр 2» и так далее.
- 🎯 **Два вида цели** — глушить можно **процесс Windows** или **звуковой источник OBS** (например, музыку, добавленную в сцену). Параметры (порог, затухание, задержка возврата) одинаковые.
- 🎬 **Выбор сцены и источника из списков** — плагин сам находит все звуковые источники выбранной сцены, включая вложенные сцены и группы. Отдельный пункт показывает глобальные источники (микрофон, звук рабочего стола).
- 🔎 **Поиск приложения по мере ввода** — начните вводить имя, и список запущенных процессов отфильтруется. Кнопка обновления с иконкой перечитывает список, если приложение запущено уже после открытия окна.
- 🔇 **Плавное приглушение и возвращение звука** — громкость меняется постепенно за заданное время, без резких скачков. После приглушения возвращается та громкость, которая была у приложения до него.
- 🧩 **Несколько фильтров на одно приложение** — приложение приглушается, если порог превышен хотя бы в одном из них.
- ⏱️ **Задержка возврата звука** — паузы в источнике (речь, оповещения, TTS) не приводят к тому, что приложение то глушится, то возвращается.
- 🌍 **Русский и английский интерфейс** — язык берётся из настроек OBS.
- 🎨 **Интерфейс в стиле OBS и две темы** — тёмная (по умолчанию) и светлая, переключаются в самом окне плагина и запоминаются. Скриншоты в разделе [Интерфейс и темы](#-интерфейс-и-темы).
- ⚙️ **Настройка через интерфейс OBS** — не нужно редактировать конфиги вручную. Окно остаётся открытым после сохранения.
- 💾 **Настройки сохраняются в файл** — фильтры, их названия, цели и тема окна запоминаются в `config.json`, после перезапуска OBS настраивать заново ничего не нужно.
- 🛟 **Восстановление громкости** — если OBS закрылся или упал во время приглушения, исходная громкость вернётся при следующем запуске.
- 🪶 **Лёгкий и без внешних зависимостей** — нативная DLL, работает через Windows Core Audio API, .NET на компьютере не нужен.

## 🎯 Зачем это нужно

Классический сценарий

| Ситуация | Что делает плагин |
|---|---|
| Вы говорите в микрофон | Звук игры/музыки/браузера приглушается |
| Вы замолчали | Звук приложения плавно возвращается |
| В источнике тишина | Приложение звучит как обычно |

Это удобно для стримов, записи видео, голосового чата и любых сценариев, где нежелательно, чтобы системный звук перебивал ваш голос.

## ⚙️ Как это работает

1. Для каждого фильтра плагин подключает измеритель уровня к выбранному звуковому источнику OBS.
2. Каждые 100 мс берётся самый громкий уровень источника за прошедший интервал и сравнивается с порогом фильтра. Короткие звуки между проверками не теряются.
3. Если порог превышен, плагин запоминает текущую громкость цели и плавно снижает её до нуля:
   - для **процесса Windows** он находит аудиосессии приложения с указанным именем в микшере громкости Windows. Пока приложение приглушено, это повторяется каждые 0,3 с, чтобы новые аудиосессии (например, при смене трека) тоже оказались приглушены;
   - для **звукового источника OBS** он меняет громкость источника (фейдер в микшере OBS), поэтому во время приглушения вы увидите, как фейдер опускается.
4. Когда звук во всех источниках, привязанных к цели, опускается ниже порога, плагин ждёт время задержки возврата. Если за это время звука нет, громкость плавно возвращается к запомненному значению. Звук в паузе короче задержки приглушение не снимает.
5. Если нужного источника в OBS ещё нет (например, сцены не успели загрузиться), плагин повторяет попытку привязки сам.

> Работает на уровне **аудиосессий Windows**, поэтому приложению не требуется никаких дополнительных прав или модификаций.

## 💻 Требования

- **ОС:** Windows 10 / 11 (используется Windows Core Audio API)
- **OBS Studio:** плагин разрабатывался и проверялся на версии `32.2.2`. Другие версии не проверялись.
- **.NET на компьютере:** не требуется (плагин скомпилирован в нативную DLL). Версия `10.0` нужна только для сборки из исходников.

## 📦 Установка

1. Скачайте `SmoothMuterPlugin.dll` со страницы [Releases](../../releases) или [соберите её из исходников](#-сборка-из-исходников).
2. Закройте OBS Studio.
3. Скопируйте `SmoothMuterPlugin.dll` в папку плагинов OBS:
   ```
   <папка OBS>\obs-plugins\64bit
   ```
   Например, для версии из Steam:
   ```
   C:\Program Files (x86)\Steam\steamapps\common\OBS Studio\obs-plugins\64bit
   ```
4. Запустите OBS Studio.

> После запуска плагин появится в меню **Сервис → Автоприглушение приложений** (в английском OBS — **Tools → App Audio Ducking**).

## 🎛️ Настройка

1. Откройте OBS Studio.
2. Перейдите в меню **Сервис → Автоприглушение приложений**.
3. Нажмите **Добавить фильтр**. Сначала фильтров нет, добавлять их можно сколько угодно. Каждый фильтр это отдельная карточка со своими полями:

   | Поле | Описание | Пример |
   |---|---|---|
   | **Название** | Поле в заголовке карточки. Название можно менять, оно сохраняется. У нового фильтра это «Фильтр 1», «Фильтр 2» и так далее (берётся первый свободный номер) | `Музыка при разговоре` |
   | **Сцена** | Сцена OBS, в которой находится отслеживаемый источник. Пункт `(Глобальные источники звука)` показывает глобальные источники: микрофон, звук рабочего стола | `Игра` |
   | **Источник звука** | Звуковой источник выбранной сцены, за уровнем которого следит плагин. Доступен после выбора сцены, при смене сцены сбрасывается | `Микрофон` |
   | **Что глушить** | Вид цели: **Процесс Windows** или **Звук в OBS**. От выбора зависят следующие поля | `Процесс Windows` |
   | **Процесс (без .exe)** | Только для процесса Windows. Приложение, звук которого нужно глушить. Начните вводить имя, и список отфильтруется. Кнопка обновления справа от поля перечитывает список запущенных процессов. Имя можно ввести и вручную | `chrome` |
   | **Сцена цели** и **Источник цели** | Только для звука в OBS. Сцена и звуковой источник, который нужно глушить. Список источников берётся из выбранной сцены. По умолчанию подставляется та же сцена, что выбрана для отслеживания. Отслеживаемый источник в списке не показывается: его громкость влияла бы на измеряемый уровень | `Музыка` |
   | **Порог срабатывания** | Выше этого уровня звука в источнике начинается приглушение | `-60` dB |
   | **Время затухания** | За сколько времени звук приложения плавно снижается и возвращается | `600` мс |
   | **Задержка возврата** | Сколько времени после тишины в источнике приложение остаётся приглушённым. Нужна, когда в источнике есть паузы (речь, оповещения, TTS): пока пауза короче задержки, звук приложения не возвращается и не глушится заново. Подробное объяснение показывает значок «?» рядом с полем | `1500` мс |

   Кнопка **Удалить фильтр** убирает фильтр.

4. Нажмите **Сохранить**. Настройки применяются сразу, окно остаётся открытым, можно продолжать добавлять фильтры.

Справа вверху можно выбрать **Тему** окна: тёмную или светлую. Тема применяется сразу и запоминается, отдельно сохранять её не нужно (см. [Интерфейс и темы](#-интерфейс-и-темы)).

Готово! Теперь при появлении звука в выбранных источниках звук указанных приложений будет автоматически приглушаться.

> 💡 **Подсказка:** если нужного источника нет в списке, проверьте, что он добавлен в выбранную сцену и имеет звук. Список источников обновляется при каждом открытии выпадающего списка.

> 💡 **Подсказка:** имя процесса можно посмотреть в Диспетчере задач → вкладка «Подробности», либо найти в списке плагина. Если вы ввели имя с `.exe`, плагин уберёт расширение сам.

> 💡 **Подсказка:** вид цели и обе пары полей (процесс и источник OBS) хранятся в фильтре одновременно, поэтому при переключении «Что глушить» введённое не пропадает.

## 🎨 Интерфейс и темы

Окно настроек оформлено в стиле OBS: те же цвета, скругления и поведение элементов, что в темах Yami. Доступны две темы, переключатель **Тема** находится справа вверху.

**Тёмная тема** (по умолчанию):

![Окно настроек, тёмная тема](docs/screenshots/settings-dark.png)

**Светлая тема**:

![Окно настроек, светлая тема](docs/screenshots/settings-light.png)

Что есть в окне:

- сверху кнопка **Добавить фильтр** и выбор темы;
- каждый фильтр это карточка со своим названием (поле в заголовке) и кнопкой **Удалить фильтр**;
- выбор вида цели (**Процесс Windows** или **Звук в OBS**), после которого показываются поля процесса или сцены и источника цели;
- справа от поля процесса кнопка обновления списка запущенных приложений;
- значок **«?»** рядом с задержкой возврата показывает подсказку, зачем нужна эта настройка;
- снизу кнопка **Сохранить**, после нажатия рядом на пару секунд появляется «Настройки сохранены».

Тема применяется сразу при выборе, введённые, но ещё не сохранённые значения фильтров при этом не теряются. Выбор запоминается в `config.json` (поле `theme`), поэтому при следующем открытии окна тема не меняется. Размер текста берётся из настройки «Масштаб шрифта» в OBS, а размеры элементов подстраиваются под масштаб экрана Windows.

## 🌍 Язык интерфейса

Язык окна настроек и названия плагина в меню берётся из языка OBS: для русского OBS интерфейс русский, для остальных языков английский.

Пункт меню **Сервис** создаётся один раз при запуске OBS, поэтому после смены языка в OBS перезапустите его, как и для самого OBS.

## 🧰 Файлы плагина и диагностика

| Что | Где |
|---|---|
| Настройки (фильтры, названия, цели, тема) | `%APPDATA%\obs-studio\plugin_config\SmoothMuterPlugin\config.json` |
| Файл восстановления громкости (появляется только на время приглушения) | `%APPDATA%\obs-studio\plugin_config\SmoothMuterPlugin\ducked_volumes.txt` |
| Журнал плагина | `%LOCALAPPDATA%\Temp\ProcessMuter_debug.log` |

В журнал пишутся загрузка плагина, обновление фильтров, привязка к источникам, а также моменты приглушения и возвращения звука. Если приложение не глушится, проверьте журнал:

- `OBS source '...' not found` — источника с таким именем нет в OBS. Проверьте, что фильтр настроен на существующий источник.
- Нет записей `Mute` при звуке в источнике — уровень не достигает порога. Попробуйте поднять порог (например, с `-60` до `-40` dB).
- Приложение остаётся приглушённым, хотя в источнике «ничего не слышно» — в журнале каждые 15 секунд пишется причина, например `Still muted 'Яндекс Музыка' for 45 s: 'discord' -58,9dB > -60,0dB`. Это значит, что фоновый шум источника выше порога. Поднимите **Порог срабатывания** выше этого уровня (например, до `-45` dB).
- Звук приложения «дёргается» (то приглушается, то возвращается) — увеличьте **Задержку возврата** в фильтре. В журнале видно, через сколько мс после тишины произошёл `Unmute`.
- `Mute` есть, но звук приложения не меняется — проверьте имя процесса: оно должно совпадать с именем в Диспетчере задач без `.exe`, а приложение должно воспроизводить звук через устройство вывода по умолчанию.

Файл `config.json` можно править вручную, формат:

```json
{
  "version": 2,
  "theme": "dark",
  "filters": [
    {
      "name": "Музыка при разговоре",
      "scene_name": "Игра",
      "source_name": "Микрофон",
      "target_type": "process",
      "process_name": "chrome",
      "target_scene": "",
      "target_source": "",
      "threshold_db": -60,
      "fade_ms": 600,
      "hold_ms": 1500
    },
    {
      "name": "Фоновая музыка в OBS",
      "scene_name": "Игра",
      "source_name": "Микрофон",
      "target_type": "obs_source",
      "process_name": "",
      "target_scene": "Игра",
      "target_source": "Музыка",
      "threshold_db": -50,
      "fade_ms": 400,
      "hold_ms": 1500
    }
  ]
}
```

- `target_type` принимает `process` (процесс Windows, поле `process_name`) или `obs_source` (звуковой источник OBS, поля `target_scene` и `target_source`). Оба набора полей хранятся всегда.
- Пустое значение `scene_name` или `target_scene` означает глобальные источники.
- Пустое `name` заменяется названием по умолчанию («Фильтр N»).
- Поле `theme` принимает `dark` (по умолчанию) или `light`.
- Файлы старых версий плагина читаются без изменений: отсутствующие поля получают значения по умолчанию, а настройки самой первой версии (один источник и один процесс) превращаются в один фильтр.

## ⚠️ Ограничения

- Плагин запоминает громкость каждой аудиосессии приложения в момент начала приглушения и возвращает именно её. Если вы сами меняете громкость приложения в микшере Windows во время приглушения, при возврате она будет перезаписана запомненным значением.
- Приглушённое приложение проверяется каждые 0,3 с: если оно создало новую аудиосессию (смена трека, новая вкладка браузера) или само сбросило громкость, плагин приглушает её снова.
- Плагин управляет громкостью только на устройстве вывода Windows **по умолчанию**.
- Приложение должно воспроизводить звук, чтобы у него была аудиосессия в микшере Windows.
- Если OBS закрыть в момент приглушения, громкость приложений возвращается к исходной при штатной выгрузке плагина.
- Громкость звукового источника OBS хранится в коллекции сцен. OBS сохраняет её при закрытии **до** выгрузки плагинов, поэтому если закрыть OBS в момент приглушения источника, в сохранение может попасть сниженная громкость. Для этого плагин записывает исходные громкости в `ducked_volumes.txt` и при следующем запуске возвращает их, как только источник загрузится (ждёт до 10 минут). То же происходит после аварийного завершения OBS, а для процессов Windows это исправляет громкость, которую Windows запомнила для приложения.
- Если во время приглушения вручную менять фейдер приглушаемого источника OBS, при возврате громкость будет заменена исходной (запомненной в начале приглушения).
- Источник OBS, за которым следит фильтр, нельзя выбрать его же целью.
- Переименование сцены или источника в OBS нужно повторить в фильтре: связь идёт по имени.

## 🔨 Сборка из исходников

### Предварительные требования

- [.NET SDK 10](https://dotnet.microsoft.com/download) (версия из `SmoothMuterPlugin.csproj`)
- Visual Studio с компонентом **«Разработка классических приложений на C++»**: он нужен для компоновщика NativeAOT
- Git

### Шаги

```bash
# 1. Клонируем репозиторий
git clone https://github.com/VallFreya/Obs.ProcessMuterByChannel.git
cd Obs.ProcessMuterByChannel

# 2. Собираем в Release
dotnet publish -c Release -r win-x64

# 3. Готовая библиотека появится в:
#    bin\Release\net10.0-windows\win-x64\publish\SmoothMuterPlugin.dll
```

Если компоновщик сообщает, что не найден `vswhere.exe`, выполните сборку из «Developer PowerShell for VS».

Скопируйте `SmoothMuterPlugin.dll` в папку плагинов OBS (см. раздел [Установка](#-установка)) и перезапустите OBS.

## 🗂️ Структура проекта

| Файл / папка | Назначение |
|---|---|
| `Plugin.cs` | Точка входа плагина: регистрация в OBS, колбэки загрузки/выгрузки, чтение и запись конфига |
| `PluginConfig.cs` | Модель конфига: список фильтров (название, отслеживаемый источник, цель, параметры), тема и миграция старого формата |
| `ObsSourceBackend.cs` | Цель «звуковой источник OBS» (громкость источника), выбор цели по ключу и файл восстановления громкости |
| `SettingsForm.cs` | Окно настроек со списком фильтров |
| `ThemedControls.cs` | Собственные контролы в стиле OBS: кнопка, поле ввода, список с поиском, карточка, подсказка |
| `ObsTheme.cs` | Две темы интерфейса (тёмная и светлая) на палитрах OBS Yami |
| `Ui.cs` | Масштаб DPI, шрифты, значки, оформление заголовка окна |
| `Loc.cs` | Тексты интерфейса на русском и английском, язык берётся из OBS |
| `ObsSceneApi.cs` | Список сцен OBS и звуковых источников сцены |
| `AudioMutesManager.cs` | Следит за источниками всех фильтров (volmeter OBS, пик уровня за интервал) и передаёт результат в `DuckingEngine` |
| `DuckingEngine.cs` | Решает, когда приглушать и возвращать громкость целей (процессов Windows и источников OBS), делает плавное затухание, держит задержку возврата, повторно применяет громкость к приглушённым процессам и восстанавливает громкость после аварийного выхода |
| `ProcessAudioControl.cs` | Работа с аудиосессиями процесса и список запущенных процессов через Core Audio API |
| `docs/screenshots/` | Скриншоты окна настроек для README (тёмная и светлая темы) |
| `Properties/` | Ресурсы и метаданные проекта |
| `SmoothMuterPlugin.csproj` | Файл проекта C# |
